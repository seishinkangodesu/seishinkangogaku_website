# 資料投入口 セットアップ手順

教員本人が資料（PDF・画像）を投入すると、サイトの「もっと詳しく見る」内に
自動で表示される仕組みの設置手順。まず藤本先生の分のみ作る。

---

## 全体の流れ

```
先生            Googleフォーム        スプレッドシート        サイト
              （＝投入口）          （回答が溜まる）

 投入  ───▶   資料がドライブへ  ───▶  1行追加  ───▶  一覧に表示
                    │                                （下書きは
                    ▼                                 プレビューのみ）
              スクリプトが自動で
              公開設定を付与
```

投入口のURLが「これは藤本先生の資料である」という情報を持つため、
**どのGoogleアカウントから投入しても構わない**。大学アカウントである必要はない。

---

## 1. 用意するもの

- 領域（研究室）名義のGoogleアカウント **1つ**（サイト運用に使用中のもの）
- 以降の作業は、すべてこのアカウントにログインした状態で行う

> **大学アカウント（@hyo-med.ac.jp）は、設置にも投入にも使えない。**（実測で確定）
> 学外共有が管理者により禁止されているため、資料をサイト訪問者に見せられず、
> 教員が外部フォームにファイルを添付することもできない。
> 投入する教員には**個人のGmail**を使ってもらう。詳細は親フォルダの README.md を参照。

---

## 2. 投入口（Googleフォーム）を作る

Googleフォームを新規作成し、次の4問を作る。

| 質問 | 形式 | 必須 | 備考 |
|---|---|---|---|
| タイトル | 記述式 | ○ | 一覧に太字で出る |
| 説明 | 段落 | — | タイトルの下に出る |
| 資料 | ファイルのアップロード | ○ | 複数可。PDF・画像 |
| 公開状態 | ラジオボタン | ○ | 下記のとおり |

**「公開状態」の選択肢は、この3つを一字一句このとおりに作る**
（サイトとスクリプトが文字で判定するため）。

```
下書き
公開
削除
```

既定値は「下書き」にしておくと安全。

### フォームの設定（重要）

「設定」タブで以下を有効にする。**ここを忘れると、投稿者が自分で修正・削除できなくなる。**

- [x] **回答の編集を許可する**
- [x] **回答のコピーを回答者に送信** → 「常に」
- [x] メールアドレスを収集する

---

## 3. 回答スプレッドシートをウェブに公開する

1. フォームの「回答」タブ → スプレッドシートのアイコンで回答先を作成
2. そのスプレッドシートで **ファイル → 共有 → ウェブに公開**
3. 形式を **カンマ区切り形式（.csv）** にして「公開」
4. 表示されたURLを控える（`.../pub?...&output=csv` という形）

---

## 4. 自動公開・自動非公開のスクリプトを入れる

1. スプレッドシートで **拡張機能 → Apps Script**
2. 既定のコードを消し、[auto-share.gs](auto-share.gs) の中身を貼り付けて保存
3. 関数 `setupTriggers` を選んで **実行**（初回のみ。権限の承認を求められる）
4. 続けて関数 `syncSharing` を **実行** し、ログにエラーが出ないことを確認

これで、投入された資料は自動で閲覧可能になり、
**状態を「削除」に変えると自動で非公開に戻る**。

---

## 5. サイト側にURLを設定する

`index.html` の `DOC_SOURCES` に、手順3で控えたURLを貼る。

```js
const DOC_SOURCES = {
    fujimoto: 'ここにCSVのURL'
};
```

貼ってコミット・プッシュすれば反映される。
URLが空のままなら、そのセクションはサイトに一切表示されない。

---

## 6. 動作確認

以下を実際に試して、期待どおり動くことを確かめる。

1. 「下書き」で1件投入 → 一般のURLでは**見えない**こと
2. `?preview=<合言葉>` 付きのURLでは**見える**こと（URLは親フォルダの README.md に記載）
3. 資料をクリックすると、ダウンロードせずその場で開くこと
4. 確認メールの「回答を編集」から「公開」に変更 → 一般のURLでも見えること
5. 同じリンクから「削除」に変更 → サイトから消え、資料のURLも開けなくなること

---

## 注意点

- **プレビューの合言葉は、ページのソースを見れば分かる。**
  下書きは「たまたま来た人には見えない」程度の保護であり、秘密は守れない。
  **未発表データや投稿中の論文は投入しないこと。**
- 確認メールを消すと、投稿者自身では修正・削除ができなくなる。
  「資料投入」のラベルを作って残す運用を勧める。
- 状態を「削除」にしても、スプレッドシートの行とドライブのファイルは残る
  （非公開になるだけ）。完全に消すには、アカウント保持者が手動で削除する。
- 石田先生の分は、藤本先生の分の動作確認が済んでから同じ手順で複製する。
